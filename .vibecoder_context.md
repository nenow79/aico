# aico – Terminal LLM Chat Harness

## Cel projektu
Proste narzędzie terminalowe do czatowania z modelami LLM.
Zastąpienie przekombinowanego harness'u Streamlit (OpenRouterChat).
Obsługuje modele prywatne (OpenRouter) i firmowe (LiteLLM przez proxy Bosch).
Tryb w pełni automatyczny MCP – serwery ładowane z pliku konfiguracyjnego.

## Technologie
- Python 3.11+, wirtualne środowisko (venv)
- Terminal UI: `prompt_toolkit` lub `rich` (TBD)
- HTTP: `requests`
- MCP: `fastmcp`
- Tokeny: `tiktoken`
- Konfiguracja: JSON / YAML
- Eksport: Markdown

## Kluczowe decyzje
- Brak bazy danych (SQLite) – historia tylko w pamięci sesji
- Brak dołączania plików
- Brak Streamlit
- MCP: wyłącznie tryb automatic (pełna automatyzacja bez zatwierdzania)
- Serwery MCP z pliku konfiguracyjnego (nie z DB)
- Modele z pliku konfiguracyjnego (models.json lub config.yaml)
- Eksport czatu do Markdown
- Licznik tokenów w UI (inline)
